# Encode and decode texts to pixels

use the Encoder to put your secret message into pixel colors then pass the ENCODED.PNG file to the Decoder and it will show your message

for more security a KEY will be added by Encoder witch the client will choose
### Knowing the key is necessary to get the right message.

This program is a simple Encoder/Decoder using Pillow library.
It transfers each character to a color using the UNICODDE system and pixel color codes.


## Requirements

- Python 3.10+
- Tkinter (included with standard Python installation)
- Pillow 13.0.0
